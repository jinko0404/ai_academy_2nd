- 내가 설명하는 의미: /api/knowledge url로 Get 메서드 요청이 들어올 시 해당 경로의 지식 목록을 반환한다.

- 저장을 호출하는 위치: main.py의 write_data(data)
- 파일에 쓰는 함수: storage.py의 write_data(data: dict) -> None
- 입력·반환·변경되는 것:
    - 입력 되는 것: entries 목록과 next_id를 포함한 전체 데이터 딕셔너리
    - 반환 되는 것: None
    - 변경 되는 것: data/knowledge.json 파일이 전달받은 데이터로 갱신됨

<!-- TODO B06-R3: 다음 세 항목의 역할이 다른 이유를 한 문장씩 적으세요. -->
- KnowledgeWrite: 입력 데이터의 필수 필드·자료형·길이를 검증하는 클래스입니다.
- read_data / write_data: 데이터를 읽어들여 읽은 데이터를 반환/전달받은 전체 상태를 Json 파일에 저장하는 함수
- data/knowledge.json: 실제 데이터 값이 키:값 형태로 저장된 파일
