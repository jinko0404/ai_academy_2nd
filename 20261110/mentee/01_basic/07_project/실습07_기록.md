# 실습 07 · 함께 확인한 결과

초기 3건에서 정확히 한 번 등록했을 때만 id=4입니다. 응답에서 받은 ID를 기록하세요.
실제 ID: 4

| 동작 | 예상 | 실제 | 파일 확인 |
|---|---|---|---|
| 정상 등록 | 201, 새 id | 201, id = 4 | knowledge.json 새 항목 추가, next_id 1 증가 |
| 같은 id 상세 조회 | 200, 등록 내용 |200, id=4의 등록 내용 반환 | knowledge.json 조회 전후 파일 변경 없음 |
| 같은 id 본문 수정 | 200, 같은 id | 200, id=4의 수정 내용 반환 | knowledge.json 본문 변경 후 변경 내용 적용 완료 및 next_id, 항목 수 유지|
| 없는 id 수정 (정상 Body) | 404 | 404 | 변경 사항 없음 |
| content 빈 문자열 등록 | 422, 파일 불변 | 422, 파일 불변 | 422 응답 반환 후 변경 사항 없음 |
| 같은 id 삭제 | 204, 빈 본문 | 204 빈 본문 반환 | knowledge.json의 id=4 항목 삭제 |
| 삭제한 id 조회 | 404 | 404 {"detail": "Knowledge not found"} 반환 | 조회후 knowledge.json 변경사항 없음 |

응답의 성공과 파일 저장 성공을 어떻게 함께 확인했는가: 상태코드 (조회, 수정:200, 등록 : 201, 삭제: 204)을 확인한 후에 실제 데이터가 저장된 json 파일을 확인했다.
이 API는 지식을 관리하는가, 질문의 답변을 생성하는가: 지식 목록 데이터를 조회(전체, 상세), 수정, 삭제, 추가 하는 CRUD 관리를 하는 API다.
