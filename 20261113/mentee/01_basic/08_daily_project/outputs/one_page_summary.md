## 3. 결과 해석

| 배운 개념 | 내 결과를 보고 설명하기 |
|---|---|
| Token·Context | 문장을 여섯 조각으로 나누고 시작·끝 토큰을 붙여 총 8개가 되었다. 지정한 길이 제한 12보다 적어 잘리지 않았다. |
| Embedding·Cosine | 예시 벡터 A-B는 유사도가 약 0.9701로 방향이 비슷하고, A-C는 -1로 반대 방향이다. |
| Attention·Causal Mask | Softmax로 참고 비율을 계산해 각 행의 합이 1이 되었다. 미래 위치를 미리 참고하지 못하도록 막아 해당 가중치는 모두 0이 되었다. |
| Softmax·Greedy | 점수 [2, 1, 0]을 약 [66.52%, 24.47%, 9.00%]의 확률로 바꾸고, 가장 높은 출력A를 선택했다. |
| 학습과 추론 | 학습은 예측 오류를 줄이도록 모델 내부 가중치를 바꾸고, 추론은 가중치를 바꾸지 않고 출력을 계산한다. 이번에는 주어진 점수로 출력 선택만 연습했다. |

## 4. 한계와 알게 된 점

- 실제 수행한 것: 예제 코드를 실행하여 토큰화, 벡터 유사도, Attention 가중치, 후보별 확률과 선택 결과를 확인했다.
- 수행하지 않은 것: 실제 사전학습 LLM 호출·학습, RAG 검색, Agent 도구 실행.
- 결과 해석 시 주의점: 미리 정한 숫자를 계산한 결과이므로, 실제 문장 의미를 이해하거나 정확한 답변을 생성했다고 볼 수 없다.
- 가장 확실히 이해한 것: 실행 결과는 확인했지만, 각 계산의 의미와 실제 LLM에서 연결되는 과정은 아직 충분히 이해하지 못했다.
- 더 공부할 것: 문장 하나가 토큰, 벡터, Attention, 출력 점수를 거쳐 다음 토큰으로 이어지는 과정을 실제 실행 예제로 다시 공부할 필요가 있다.
