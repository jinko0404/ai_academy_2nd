실습 05 청크 커버리지 검증 보고서

작성자: 고진석

20자짜리 예제로 청크가 덮은 문자 비율(Coverage), 누락 위치, ID 중복을 검사했다.

- 겹침 예제는 4자가 겹쳤지만 전체 20자를 덮었고, 중복 ID가 없어 통과했다(100%).
- 누락 예제는 인덱스 8과 9의 문자 2개가 빠져 실패했다(90%).
- 중복 예제는 전체 20자를 덮었지만 ID A가 반복돼 실패했다(100%).

결론: 커버리지가 100%여도 검증을 통과하려면 청크 ID가 서로 달라야 하며,
프로그램은 커버리지와 ID 중복 여부를 별도로 검사해야한다.
