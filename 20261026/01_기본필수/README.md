# 모델 선택 보고서

## 1. 목표
- 예측하려는 문제: 작업 소요 시간 및 실패 여부 예측
- 회귀 목표값: elapsed_ms
- 분류 목표값: failed

## 2. 실험 조건
- 데이터 분할: train(60%) / valid(20%) / test(20%)
- 입력 특성: input_chars(입력 데이터 글자 수), task_type(작업 종류)
- 전처리 방법: StandardScaler(숫자형인 input_chars의 값 범위를 조정), OneHotEncoder(문자형인 task_type의 범주를 모델이 처리할 수 있는 숫자 형태로 변환)
- 테스트 데이터 사용 여부: test는 학습·예측하지 않았습니다.

## 3. 회귀 모델 선택
- 비교한 모델:Dummy, Linear
- 주 평가 지표: MAE_ms
- 가장 적합하다고 판단한 모델: Linear
- 선택 이유: MAE_ms(예측값과 실제값의 차이)가 각각 253.75ms, 17.89ms로 200ms 이상 차이 나기에 둘중 가장 적합하다 판단했습니다.

## 4. 분류 모델 선택
- 비교한 모델:Dummy, Logistic
- 주 평가 지표:F1
- 가장 적합하다고 판단한 모델:F1만으로는 판단하기 어려움
- 선택 이유: 두 모델 모두 F1이 0.0으로 동일했다. 검증 데이터에서 실제 실패 사례를 두 모델 모두 찾아내지 못했으므로, F1 점수만으로 모델의 우열을 판단할 수 없다.

## 5. 예측 오류 사례
- 확인한 데이터 ID: B004
- 실제 정답: 1
- 모델 예측: 0
- 이 오류가 의미하는 점: 실제로 실패한 작업을 성공으로 예측하여, 실패 가능성을 사전에 감지하지 못했다.

## 6. 한계와 다음 계획
- 현재 실험의 한계: 데이터가 20개로 적고, 검증 데이터도 4개뿐이라 모델의 성능을 정확하게 판단하기 어려우며, 분류 모델 두 개 모두 F1이 0.0으로, 실패 사례를 제대로 예측하지 못했다.
- 다음에 확인하거나 개선할 점: 더 많은 데이터와 실패 사례를 더 확보하고, 실패를 얼마나 잘 찾아내는지 재현율(Recall)도 확인해야 합니다.
