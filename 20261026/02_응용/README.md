## 3. 분류 모델 비교 및 선택
- 비교한 모델: Dummy, Logistic, KNN3
- 주 평가 지표: F1
- 선택한 모델: KNN3
- 선택 이유: F1은 실패를 찾아내는 정밀도와 재현율을 함께 평가하는 지표로 종합적으로 두 수치를 고려할 수 있기에 선택했습니다.
- FP와 FN 결과 해석: FP는 실제로는 성공인데 실패라고 예측한 건수이며, FN은 실제로는 실패지만 성공이라고 예측한 건수다.
- 모델의 한계: KNN3는 Dummy보다 실패를 더 많이 찾아냈지만 실제 실패 6건 중 3건은 여전히 놓쳤기에 완전 무결한 모델은 아니다.

## 4. 테스트 데이터 분리 이유
- 테스트 데이터를 학습 및 모델 선택에 사용하지 않은 이유: 테스트 데이터는 최종 성능 평가에 쓰일 데이터 이며 이를 미리 쓸 경우 제로 처음 보는 데이터에서도 잘 작동하는지 공정하게 평가하기 어려워지기 떄문에 모델 선택 및 학습에 쓰이지 않는다.
- 테스트 데이터의 역할: 실제 학습하고 검증한 모델을 최대한 공정하게 최종적으로 모델을 평가하는 데이터다.

## 5. 실험 결과의 한계와 개선 방향
- 현재 실험의 한계: KNN3의 F1은 0.545로 세 분류 모델 중 가장 높았지만, 실제 실패 6건 중 3건을 놓쳤기에 완전 무결한 모델이라고 확정 지을 수 없다.
- 다음에 확인하거나 개선할 점: Recall을 추가로 확인하고, 실패 사례를 더 많이 찾아낼 수 있도록 다른 모델이나 분류 기준을 비교해야한다.

## 6. 최종 정리
- 이번 실험에서 확인한 점: 분류 모델은 F1 점수만 보는 것이 아니라, 실제 실패를 얼마나 찾아내는지도 확인해야 한다.
- 실제 적용 전에 추가로 검증할 사항: 더 다양한 데이터를 사용해 모델 성능이 유지되는지 확인해야한다.
