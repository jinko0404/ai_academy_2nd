## 🧠 주요 학습 분야

### Python & Data Analysis
- Python 프로그래밍 및 데이터 처리
- Pandas를 활용한 데이터 분석
- 실습 데이터 정리 및 결과 저장

### Machine Learning
- 분류(Classification)와 회귀(Regression)
- 결정 트리(Decision Tree)
- 랜덤 포레스트(Random Forest)
- XGBoost
- 특성 중요도(Feature Importance)

### Model Evaluation
- 학습 데이터와 검증 데이터의 분리
- 교차검증(Cross-Validation)
- F1 Score 및 RMSE 등 평가 지표
- 모델별 성능 비교와 오류 분석
- 데이터 누수 방지 및 평가 결과 해석

## 🔬 실습 및 결과 기록

실습에서는 코드 실행뿐 아니라 결과를 확인하고 해석하는 과정도 중요하게 다룹니다.

- 모델별 성능 지표 비교
- 교차검증 회차별 평가 결과 기록
- 실제 정답과 예측 결과 비교
- 특성 중요도 분석
- 실험의 한계와 추가 검증이 필요한 사항 정리

실험 결과는 사용한 데이터, 평가 방법 및 설정을 함께 고려하여 해석합니다. 개별 실습의 상세 내용과 결과는 각 날짜별 README에서 확인할 수 있습니다.
